# 让自己的 Codex 协助安装和使用

使用能够访问本机文件的 Mac 版 Codex。安装操作在你自己的电脑完成，学校登录由你自己在 Chrome 完成。遇到系统或浏览器要求本人操作的步骤，按 Codex 提示接手。

## 安装提示词

把仓库地址替换成发布者提供的真实 GitHub 地址，粘贴给 Codex：

```text
请从这个 GitHub 仓库的最新 Release 下载并安装“BB 资料下载助手”：
https://github.com/JiJinghan/bb-course-downloader

我使用 Mac 和 Google Chrome。请下载 Release Assets 里的
BB-Course-Downloader-macOS-版本号.zip，而不是自动生成的 Source code.zip；
同时下载 SHA256SUMS.txt，验证对应安装包的校验值，再解压。

先阅读 README.md、docs/QUICKSTART.md 和安装脚本，检查芯片架构、
Chrome 和 Python 3。若缺少依赖，先说明，并遵循本机审批要求；
不要关闭系统安全保护，不要安装来自不明来源的软件。

我授权你将这个助手安装到我用户目录的 Application Support，
为我的 Google Chrome 注册它的 Native Messaging 主机，
并协助加载包内 Chrome 扩展和打开助手面板。
请保留已有课程文件、下载历史和 Chrome 配置。
不要读取或上传密码，也不要导出 Cookie。

请实际验证安装包版本与扩展匹配，面板显示“本地助手已连接”。
如需我手动选择文件夹或处理系统弹窗，说明具体操作。
本次先安装，不开始下载课程资料。
```

如果已经手工下载并解压，把提示词开头替换成“安装包已解压到【完整路径】，请从该目录安装”，不需要重复下载。

当前版本自带 Apple Silicon 选择器。Intel Mac 若要编译，需要可用的 Apple 命令行开发工具；尚未进行 Intel 实机验证，Codex 不应把它宣称为直接支持。

## 下载提示词

先在自己的 Chrome 登录学校 BB，再修改下面的课号与目录：

```text
请使用已安装的“BB 资料下载助手”，下载 MAT1001 的全部资料，
包含能够下载的视频。
保存到我的桌面 MAT1001 课程文件夹，不存在就创建。

先查找课程并核对学期、班级；有多个匹配时让我选择。
扫描支持的资料栏目，并递归检查目标目录及子目录中的已有文件，
结合历史记录避免重复下载。
按助手规则保存结构、附件、教师链接和课程目录。

我授权你在课程匹配明确、保存位置正确时开始下载。
遇到“本地可能已存在”的文件，请让我核实。
完成后报告成功、跳过、失败和不支持的内容；
请检查实际完成状态，不要把扫描预览当成下载成功。
```

只下载某周时把第一句改成：“请使用 BB 资料下载助手，下载 ENG2001 的 W7 资料，包含能够下载的视频。”
