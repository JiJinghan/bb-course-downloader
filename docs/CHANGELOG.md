# 更新说明

## 1.1.0 — 2026-10-27

- 从单一 Content 入口改为扫描课程左栏多个资料栏目。
- 明确排除 Announcements / Discussions / Groups / Tools / Help，大小写不敏感；不抓这些栏目中的附件。
- 保留“栏目 / 原有文件夹 / 条目标题”的本地层级。
- 保存教师 HTTP(S) 链接为 Markdown，增加累计课程目录与重复附件位置记录。
- 同一 BB 资源只下载一次，保留其在多个栏目的出现位置。
- 纯文字条目仅在目录保留标题，不抓正文，不生成空目录。
- 自动更新生成记录；用户修改先备份，同名普通文件改用其他输出名。
- 增加结构预览、栏目与链接计数、目录记录错误及单独重试。
- 多个同名手工文件可选择具体候选，不再默认记录第一个路径。
- 将 macOS 目录选择器封装为标准应用；安装器将扩展复制到稳定的应用目录。
- 增加模块说明、状态与数据协议、排错指南及多栏目/记录保护测试。

升级保持资源 ID 历史，不移动旧文件。新下载增加栏目和条目层级，旧资料通过实际保存路径引用。原来生成的预览需重新扫描。
