# BB 资料下载助手：新手指南

适用：港中深 Blackboard Classic、M 系列 Mac、Google Chrome 120 或更新版本。当前试用版需要 Python 3；不支持 Safari 作为下载浏览器。Codex 是可选的安装帮手。

## 1. 下载正确的安装包

打开发布者给你的仓库链接 → **Releases** → 最新版本 → **Assets** → `BB-Course-Downloader-macOS-1.1.0.zip`，下载后双击解压。

不要下载 GitHub 自动生成的 `Source code.zip` 作为普通安装包；源码包不包含预编译目录选择器。

想检查安装包是否下载完整，可以在终端运行 `shasum -a 256 安装包路径`，与同版本 `SHA256SUMS.txt` 中的值比较。

## 2. 检查电脑

- 苹果菜单 → 关于本机：芯片应为 Apple M 系列。Intel 版本需要编译，暂不推荐新手直接安装。
- 已安装 Google Chrome。
- 终端运行 `python3 --version`，应显示 Python 3。若没有，从 [Python 官方网站](https://www.python.org/downloads/macos/) 安装适合该 Mac 的 Python 3，再继续；不需要安装 npm。

## 3. 安装本地助手

在解压目录双击 **安装助手.command**。安装器将程序放到你的用户目录，不需要把整个下载包一直留在 Downloads 中。

若不能通过双击启动，可以在终端输入 `python3 `（末尾有空格），把解压目录内的 `native/install.py` 拖进终端，按回车运行。系统若阻止文件打开，请先阅读系统提示和包内代码，确认来源；不要关闭系统安全保护。

成功时，终端显示“本地助手安装完成”和扩展目录路径。

## 4. 将扩展加载到 Chrome

1. Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角 **开发者模式**。
3. 点击 **加载未打包的扩展程序**。
4. 文件选择窗口按 `⌘⇧G`，输入下面路径并选择 `extension` 文件夹：

```text
~/Library/Application Support/BB Course Downloader/extension
```

5. 点击 Chrome 拼图图标中的 **BB 资料下载助手**，可将其固定到工具栏。
6. 打开面板，确认显示 **本地助手已连接**，底部版本为 **1.1**。

## 5. 第一次下载

1. 在同一个 Chrome 用户配置中登录 [学校 BB](https://bb.cuhk.edu.cn)，打开课程任一资料页面。
2. 在助手输入 `下载所有 MAT1001 资料`，点击 **查找课程**，核对学期、班级。
3. 点击 **选择 / 新建文件夹**，选择课程根目录，例如桌面上的 `MAT1001`。不要选 Lecture Notes 或 W7 子文件夹；助手会按老师结构自动创建。
4. 点击 **扫描并检查已有文件**。扫描会检查该目录及所有子目录中的已有文件，此时尚未下载。
5. 核对栏目、结构、警告。对“本地可能已存在”的文件作出选择；多个候选时选正确路径，不确定时不要直接认定相同。
6. 点击 **开始下载…并保存目录与链接**。保持 Chrome 运行，可以切换网页或关闭助手面板。
7. 完成后查看失败项和扫描警告，再到课程目录检查资料。

只下载某周可输入：`下载 ENG2001 的 W7，包含视频`。

## 6. 以后补下载

使用同一个课程目录，再查找、扫描并核实新增项。资源下载历史会帮助跳过已下载项，即使后来改名或移动，默认仍跳过。

`.bb-downloads` 是课程根目录里的隐藏文件夹，保存下载历史和目录记录。备份课程时一起保留；不要为了排错删除它。老师替换同一个资源的内容时，不会自动识别新版，需要手动选择重新下载。

## 7. 会得到什么

- 左栏栏目 / BB 子文件夹 / 内容条目标题 / 附件。
- 根目录 `课程目录.md`；有教师链接的条目内有 `链接.md`。Markdown 可用文本编辑器、Obsidian 或 VS Code 阅读。
- Announcements、Discussions、Groups、Tools、Help 按名称忽略（不区分大小写），其中附件也忽略。
- 老师的外部网站链接只保存地址；BB 附件视频和可识别的直链可下载，外部流媒体不保证支持。
- 无附件或链接的条目只记录标题，不保存正文。

## 8. 更新与反馈

更新前等待下载完成。下载新安装包，运行安装助手，再到 `chrome://extensions` 对 BB 助手点 **重新加载**，重新扫描。旧课程文件和下载历史保留。

反馈时提供版本、macOS/芯片、Chrome 版本、操作步骤、界面报错和扫描警告即可。公开 Issues 前遮住姓名、学号、课程私有链接和本地个人路径；不需要密码、Cookie 或完整课程文件。更多见 [排错指南](TROUBLESHOOTING.md)。
