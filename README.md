# BB 资料下载助手 · 1.1

为 macOS + 港中深 Blackboard Classic 制作的 Chrome 扩展。输入课程号，选择本地课程目录，扫描并核实已有文件后，一次启动后台下载。

## 下载与首次安装

当前版本为 **1.1.0 校内试用版**。适合使用 **Apple Silicon（M 系列）Mac、Google Chrome 120+、Python 3** 的港中深学生。无需安装 Codex，也无需把学校账号交给作者。Intel Mac 需要自行编译目录选择器，尚未验证直接安装。

- **下载安装包**：打开[最新版本下载页](https://github.com/JiJinghan/bb-course-downloader/releases/latest)，在 **Assets** 中下载 `BB-Course-Downloader-macOS-1.1.0.zip`。GitHub 自动提供的 `Source code.zip` 不包含预编译目录选择器，普通用户请选择上述安装包。
- **第一次使用**：[新手指南](docs/QUICKSTART.md)，从检查电脑到第一次补下载。
- **有 Codex 的同学**：[复制安装提示词](docs/CODEX_INSTALL.md)，让本机 Codex 协助检查、安装并验证。
- **遇到问题**：[排错指南](docs/TROUBLESHOOTING.md)。

这是独立的学生工具，与学校或 Blackboard 官方无隶属关系。它使用你自己 Chrome 的 BB 登录状态；仅分享工具，安装包不含课程附件、账号或个人下载历史。


## 日常使用

1. 在同一个 Chrome 用户配置中登录 `https://bb.cuhk.edu.cn`。
2. 点击工具栏的 **BB 资料下载助手**。输入 `下载所有 MAT1001 资料`，或 `下载 ENG2001 的 W7，包含视频`。
3. 点击 **查找课程**，核实学期和班级。第一次找不到时，打开该课程任一资料栏目，再查找；之后可以切换页面。
4. **选择 / 新建文件夹**：选择课程根目录，如 `Desktop/MAT1001`，不要选择其 Lecture Notes 或某一周子目录。
5. 点击 **扫描并检查已有文件**。核对“扫描栏目”、结构预览、警告和附件清单。此时还没有下载附件或生成 Markdown。
6. 已有同名文件需要你确认；同名候选超过一个时可选择具体位置。随后点击 **开始下载…并保存目录与链接**。没有附件、只有链接时也能保存。

BB 页面和助手面板可关闭，Chrome 需要继续运行。最多同时下载 3 个文件；失败不会把附件记为成功。可以暂停、继续或重试失败项。

## 保存结构

```text
MAT1001/
├── 课程目录.md
├── Lecture Notes/
│   ├── Week1-1, Lecture 1/
│   │   ├── 1001lec01 2023.pdf
│   │   └── 链接.md                 # 此条目有老师链接时生成
│   └── Week1-2, Lecture 2/
│       └── 1001lec02 2023.pdf
├── Midterm/
│   └── Review/
│       └── 附件位置.md             # 同一附件已保存在其他位置时生成
└── .bb-downloads/                  # 历史与生成记录，随课程一起备份
```

- 按 **左栏栏目 → BB 原有子文件夹 → 内容条目标题 → 附件** 保存。条目标题本来不是 BB 文件夹，也会成为本地目录。
- 同一条目多个附件放在一起；附件保持服务器提供的原文件名。路径中非法字符替换为下划线，过长名称缩短；同级重名标题附加稳定标识。
- **Announcements、Discussions、Groups、Tools、Help** 按左栏名称匹配，去除首尾空格、不区分大小写；栏目内的附件和链接一并忽略。
- Home Page 等仪表盘、工具入口不作为资料目录。其余受支持的资料栏目都扫描，不再只找名为 Content 的入口。
- 普通栏目中的纯文字条目只在总目录记录标题与“无附件或链接”，不保存正文、不创建空文件夹。
- 老师的 HTTP(S) 链接保存到对应条目的 `链接.md` 和总目录。不访问或下载外部网页，也不把外部 PDF 链接当作已下载附件。
- 同一 BB 资源在多个栏目出现：下载一份，目录保留所有引用。资源 ID 不同的同名文件不会合并。

## 已有文件、改名和增量扫描

选定目录及所有子目录都会递归检查，包括你自己创建的目录。

| 情况 | 行为 |
|---|---|
| 有资源 ID 下载历史 | 默认跳过；即使你改名、移动、编辑或删除，也不擅自重新下载 |
| 无历史，但找到同名文件 | 标为可能已存在，忽略大小写，由你核实 |
| 文件名带 `(1)` 或已改名 | 目前不做模糊匹配；可选“已手动下载，记入历史” |
| 多个同名候选 | 选择正确的本地位置，或明确“只记录曾经下载” |
| 老师新增附件 | 识别为新资源，列入下载预览 |
| 老师替换同一资源的内容 | 不自动识别新版，需要手动选重新下载 |
| 同名重新下载 | 另存带标识的副本，保留原文件 |

升级后不移动、重命名或覆盖旧课程文件。新下载按新结构保存；目录会指向已确认的旧位置。原位置失效时会明确标注，不假装知道文件的新位置。

## Markdown 的更新与保护

`课程目录.md` 是累计记录。只扫 W7 或某个栏目读取失败，不会删除之前收集的结构；旧条目标为“来自此前扫描，未在本次范围内重新核实”。老师撤回内容时也不删除本地资料。

每次确认任务后和本轮附件处理结束后更新记录。目录区分已下载、人工核实、未下载、跳过、失败，避免把扫描到的资源误写成已下载。

- 助手生成的 Markdown 没有被你改过：正常更新。
- 被你改过：先保存同目录下的 `*.用户修改备份-标识.md`，再生成新版；不自动合并你的笔记。
- 第一次生成时已有同名普通文件：改用 `课程目录（BB助手）.md` 等名称，不覆盖它。
- 目录更新失败：附件结果仍保留，面板显示独立错误，可点 **重试更新目录记录**，无需重下附件。

## 安装与升级

1. 双击 **安装助手.command**，或在项目目录运行 `python3 native/install.py`。
2. Chrome 打开 `chrome://extensions`，开启开发者模式，点“加载未打包的扩展程序”。
3. 选择安装器显示的目录：`~/Library/Application Support/BB Course Downloader/extension`。在系统选择框按 `⌘⇧G` 可输入路径。
4. 点击扩展图标，确认 **本地助手已连接**。

升级前请等待当前任务完成并保留文件；运行安装器更新文件后，在扩展管理页重新加载 BB 助手。旧的扫描预览需要重新扫描；正在下载时不要重载。原先从项目 `extension/` 加载的用户仍可保留该路径，源文件也会同步修改。

固定扩展 ID：`ifblkamjhaokdephpmkhcinhkgjoedaa`。本机需要 Python 3。已包含 Apple Silicon 目录选择器；其他 Mac 可删除 `native/folder-picker` 后运行安装器，用系统 Swift 重新编译。

安装位置：

- 程序、扩展、目录选择器：`~/Library/Application Support/BB Course Downloader/`
- Chrome Native Messaging 注册：`~/Library/Application Support/Google/Chrome/NativeMessagingHosts/cn.cuhk.bb_downloader.json`
- Beta 单独安装：`python3 native/install.py --browser chrome-beta`

## 权限与边界

使用已登录的 BB 会话，不导出 Cookie、不读取密码、不上传资料，无云服务、遥测或外部 AI API。本地助手通过 Chrome Native Messaging 通信，没有网络监听端口。

自动请求/下载的域名仍限定 `https://bb.cuhk.edu.cn`。保存外链文本不扩大域名访问权限。本地助手处理选定课程目录和本扩展创建的专属暂存文件；拒绝目录越界及符号链接目标。

目前适配 Classic 的资料列表、课程菜单、`bbcswebdav` 附件及视频直链。Ultra、需执行脚本才能加载的内容、其他下载接口、外部流媒体和 DRM 暂不支持。请核对扫描栏目、附件数量和警告；尚未验证的页面不承诺完整抓取。

大文件先存入 Chrome 默认下载目录的 `_BB_Downloads/<任务标识>/`，校验后归档。短时间可能占用两份空间。Chrome 下载历史显示临时文件已移动是正常现象。
