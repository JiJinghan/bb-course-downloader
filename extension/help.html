BB 资料下载助手 · 1.1

使用顺序

  1. 在同一个 Chrome 用户配置中登录学校 BB。
  2. 输入课程号，或“下载 ENG2001 的 W7，包含视频”。找不到时，先打开该课程任一资料页面，再查找。
  3. 选择课程根目录。不要选 Lecture Notes、W7 等子目录；工具会在根目录创建完整层级。
  4. 扫描，查看扫描栏目、结构和链接预览，再核实已有文件。
  5. 点击开始。没有附件、只有链接时，也能保存目录与链接。关闭网页不影响后台下载，Chrome 需要继续运行。

什么会保存

按“左栏栏目 / BB 原有子文件夹 / 内容条目标题 / 附件”保存。同一条目的多个附件放一起，同一 BB 资源在多处出现也只保存一份，各处目录引用其实际位置。

Announcements、Discussions、Groups、Tools、Help 按名称忽略，不区分大小写，里面的附件和链接也不收取。Home Page 仪表盘及工具页面不作为资料栏目。

老师的 HTTP(S) 链接写入对应的“链接.md”和根目录“课程目录.md”，不访问外部网站。纯文字条目只在目录保留标题，不保存正文或创建空文件夹。外部视频网页记录链接；BB 提供的直接视频附件可下载。

已有文件和更新

递归扫描你选的目录及所有子目录，包括你手工创建的目录。有资源 ID 历史的附件默认跳过，改名、移动、编辑也不自动重下。无历史的旧文件按完整文件名查找，忽略大小写；含“(1)”或改过名的旧文件需手动标为已下载。

多个同名候选时选择具体路径，或明确只记历史。旧文件不重排；重新下载会另存。目录会标注无法定位的历史文件，绝不把“曾下载”当作“原路径还存在”。

课程目录是累计记录。局部扫描不会删除以前的结构，旧节点标注未重新核实。自动生成的 Markdown 被你编辑过时，更新前保存“用户修改备份”；第一次生成遇到已有普通同名文件，另用“（BB助手）”名称。

安装与升级

  1. 运行安装包的“安装助手.command”。需要 Python 3。
  2. 在 chrome://extensions 开启开发者模式，加载安装器显示的 extension 文件夹，通常是 ~/Library/Application Support/BB Course Downloader/extension。
  3. 升级时先完成当前下载，再运行安装器并在扩展管理页重新加载 BB 助手。旧预览需要重新扫描。

固定 ID：ifblkamjhaokdephpmkhcinhkgjoedaa。看到“本地助手版本较旧”表示浏览器和本地程序未同时更新。

快速排错

  • 无法选目录：确认 Mac 已解锁、目录窗口未被遮挡；不要连续点选，超时后可重试。
  • 漏栏目：检查版本和“扫描栏目”；“只扫描当前入口”表示菜单未完整识别。
  • 附件失败：查看运行记录及 chrome://downloads；登录过期后先重新登录。
  • 目录记录更新失败：附件结果仍保留，检查磁盘、权限和目录是否被移动，修复后单独重试目录记录。
  • 不要删除 .bb-downloads 来排错。history.json 是资源历史，catalog.json 是累计结构和生成文档记录。

安装包 docs 文件夹包含完整 ARCHITECTURE.md、TROUBLESHOOTING.md 和 CHANGELOG.md。报告问题时提供版本、课程号、扫描范围、错误和运行记录即可，无需密码或 Cookie。

权限与适配范围

仅对 bb.cuhk.edu.cn 发起请求，借用现有登录态，不导出 Cookie、不上传资料。外链只保存文本。本地助手仅操作选定目录及自身暂存文件，无网络监听端口。

目前支持 Blackboard Classic 静态资料列表、bbcswebdav 附件和视频直链。Ultra、脚本动态内容、其他下载接口、外部播放流、DRM 暂不支持。警告中的栏目不能视为已完整扫描。
